# ADR-006: Twenty-six bounded Rust crates

**Status:** Accepted for ClauseForge 0.1  
**Decision date:** 2026-11-20

## Context

The product must remain primarily Rust without manufacturing ceremonial modules.

## Decision

Partition by responsibility: kernel, ten domain stages, evidence, audit, persistence, replay, orchestration, eight adapters, schema and service. Service composition reaches every crate through real calls.

## Consequences

Boundaries increase compile units but make acceptance tests and ownership explicit. A crate is removed if it loses a production caller.

## Verification and reciprocal mapping

The acceptance surface is: Cargo workspace metadata, crate-call-paths.md, reciprocal tests. The corresponding implementation and failure tests must cite ADR-006; if that path is removed, this decision is reopened rather than preserved as orphaned documentation.
