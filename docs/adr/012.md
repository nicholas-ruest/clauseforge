# ADR-012: Denial recovery in one session

**Status:** Accepted for ClauseForge 0.1  
**Decision date:** 2026-11-20

## Context

Users need to understand both the guardrail and the corrective path, not just a red error.

## Decision

The UI exposes an observer role for a controlled denial, explains the held boundary, and restores reviewer access without losing the authored scenario.

## Consequences

The journey proves denial count stability and a subsequent success. Production identity selection will come from SSO rather than this explicit amendment review control.

## Verification and reciprocal mapping

The acceptance surface is: App error state, denial-recovery Playwright test. The corresponding implementation and failure tests must cite ADR-012; if that path is removed, this decision is reopened rather than preserved as orphaned documentation.
