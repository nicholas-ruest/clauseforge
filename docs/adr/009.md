# ADR-009: Explicit middleware ordering

**Status:** Accepted for ClauseForge 0.1  
**Decision date:** 2026-11-20

## Context

Layer registration can reverse intuitive order and silently permit side effects before checks.

## Decision

Document and test the executable order: correlation, authentication, authorization, timeout, route validation, domain, error mapping, observability response.

## Consequences

The stack is reviewable and failures have stable semantics. New middleware must declare before/after constraints in the matrix.

## Verification and reciprocal mapping

The acceptance surface is: middleware-order test, integration-matrix.md. The corresponding implementation and failure tests must cite ADR-009; if that path is removed, this decision is reopened rather than preserved as orphaned documentation.
