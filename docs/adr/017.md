# ADR-017: Human-controlled PR merge

**Status:** Accepted for ClauseForge 0.1  
**Decision date:** 2026-11-20

## Context

A product factory may prepare reviewable work but must not collapse publication and approval.

## Decision

The governed publisher creates a personal-account repository, pushes a branch and opens a non-draft PR; it never merges.

## Consequences

Nick retains merge authority. Publication failure leaves a complete local candidate and no substitute direct push.

## Verification and reciprocal mapping

The acceptance surface is: publication gate, publish-via-pr.sh, CI producer binding. The corresponding implementation and failure tests must cite ADR-017; if that path is removed, this decision is reopened rather than preserved as orphaned documentation.
