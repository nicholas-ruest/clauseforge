# ADR-019: Accessible stateful console

**Status:** Accepted for ClauseForge 0.1  
**Decision date:** 2026-11-20

## Context

Operational tooling fails under pressure when state is encoded only by color or hidden spinners.

## Decision

Use semantic headings, labels, live regions, focus styles, skip navigation and textual loading, empty, denial and success states.

## Consequences

The interface is keyboard-usable and responsive. Automated browser assertions cover core names; a manual screen-reader review remains a release activity.

## Verification and reciprocal mapping

The acceptance surface is: React App, CSS breakpoints, browser suite. The corresponding implementation and failure tests must cite ADR-019; if that path is removed, this decision is reopened rather than preserved as orphaned documentation.
