# ADR-024: One-command lifecycle

**Status:** Accepted for ClauseForge 0.1  
**Decision date:** 2026-11-20

## Context

A complete product must be runnable without remembering an undocumented process sequence.

## Decision

Provide start, readiness, stop, reset and seed commands with resolved repository paths, safe PID files and explicit environment bindings.

## Consequences

Local operation is repeatable. The start command assumes prerequisites already installed and fails readiness rather than silently continuing.

## Verification and reciprocal mapping

The acceptance surface is: scripts/start.sh, stop.sh, reset.sh, seed.sh. The corresponding implementation and failure tests must cite ADR-024; if that path is removed, this decision is reopened rather than preserved as orphaned documentation.
