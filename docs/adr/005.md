# ADR-005: Eight executable upstream responsibilities

**Status:** Accepted for ClauseForge 0.1  
**Decision date:** 2026-11-20

## Context

Crediting dependencies by metadata would not demonstrate product value or failure behavior.

## Decision

Bind each selected exact SHA to a typed Rust adapter and a source-verifying runtime command that performs the selected operation before emitting a unique marker.

## Consequences

Runtime is slower than an in-process mock, but receipts prove actual execution. Missing checkout, SHA mismatch, marker mismatch and command failure all fail closed.

## Verification and reciprocal mapping

The acceptance surface is: eight clauseforge-upstream crates, scripts/upstream-runtime/run.sh, integration receipts. The corresponding implementation and failure tests must cite ADR-005; if that path is removed, this decision is reopened rather than preserved as orphaned documentation.
