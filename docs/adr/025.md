# ADR-025: Benchmark with ablation

**Status:** Accepted for ClauseForge 0.1  
**Decision date:** 2026-11-20

## Context

A frontier mechanism is not established by architecture prose alone.

## Decision

Measure the eight-upstream path and compare a domain-only ablation using identical requests, recording stage coverage, latency and score change.

## Consequences

The benchmark exposes the cost and contribution of executed integrations. Results are prototype evidence, not generalized performance guarantees.

## Verification and reciprocal mapping

The acceptance surface is: scripts/benchmark.sh, scripts/ablation.sh, external suite receipts. The corresponding implementation and failure tests must cite ADR-025; if that path is removed, this decision is reopened rather than preserved as orphaned documentation.
