# ADR-003: Correlation identity propagation

**Status:** Accepted for ClauseForge 0.1  
**Decision date:** 2026-11-20

## Context

Browser, middleware, domain, upstream and storage evidence must be joinable without depending on timestamps.

## Decision

Accept or generate one UUID correlation ID at the outer middleware, place it in request extensions and response headers, then persist it in the evidence record.

## Consequences

Reviewers can trace one outcome across all boundaries. Invalid external IDs are treated as opaque strings today; a future hardening may enforce UUID syntax.

## Verification and reciprocal mapping

The acceptance surface is: clauseforge-correlation, middleware::correlation, EvidenceRecord, Playwright correlation assertions. The corresponding implementation and failure tests must cite ADR-003; if that path is removed, this decision is reopened rather than preserved as orphaned documentation.
