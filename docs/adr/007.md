# ADR-007: Reconstruct audit before append

**Status:** Accepted for ClauseForge 0.1  
**Decision date:** 2026-11-20

## Context

Blindly trusting the final stored hash could let an earlier record be altered without detection.

## Decision

Load persisted records, replay them through AuditChain, compare every rebuilt hash, and only then append the new event.

## Consequences

Each write is O(n), acceptable for amendment review evidence volume and stronger than tail-only validation. Later scaling can use signed checkpoints without weakening full verification.

## Verification and reciprocal mapping

The acceptance surface is: service create handler, clauseforge-audit, tamper tests. The corresponding implementation and failure tests must cite ADR-007; if that path is removed, this decision is reopened rather than preserved as orphaned documentation.
