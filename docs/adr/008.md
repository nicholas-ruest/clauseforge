# ADR-008: Static frontend served by Rust

**Status:** Accepted for ClauseForge 0.1  
**Decision date:** 2026-11-20

## Context

A split development topology is useful locally, but a production outcome needs one address and one health boundary.

## Decision

Build React assets with Vite and use tower-http ServeDir with index fallback from the Rust service. Development keeps a proxy server.

## Consequences

Cloud Run receives one container and one PORT. A missing frontend build is visible as a 404 while API readiness remains separately testable.

## Verification and reciprocal mapping

The acceptance surface is: service router fallback, frontend build, Containerfile. The corresponding implementation and failure tests must cite ADR-008; if that path is removed, this decision is reopened rather than preserved as orphaned documentation.
