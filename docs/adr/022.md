# ADR-022: Separate source-backed and precheck history

**Status:** Accepted for ClauseForge 0.1  
**Decision date:** 2026-11-20

## Context

Runs without a repository cannot truthfully supply a source SHA or immutable project URL.

## Decision

Selection report history contains only attributable source-backed attempts. PRECHECK_HISTORY separately records run identity, date and recorded result.

## Consequences

Rotation audits consider both ledgers without fabricating schema fields. Missing source attribution remains explicitly unknown.

## Verification and reciprocal mapping

The acceptance surface is: selection-report.json, private PRECHECK_HISTORY.json. The corresponding implementation and failure tests must cite ADR-022; if that path is removed, this decision is reopened rather than preserved as orphaned documentation.
