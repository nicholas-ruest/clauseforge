# ADR-004: Typed API as a versioned boundary

**Status:** Accepted for ClauseForge 0.1  
**Decision date:** 2026-11-20

## Context

Handwritten UI fetch calls tend to drift from Rust request and response structures.

## Decision

Keep API v1 types in clauseforge-api-schema, publish OpenAPI JSON, and check the TypeScript client fingerprint and property set against it.

## Consequences

The UI retains independent TypeScript ergonomics while drift fails CI. Schema changes require an explicit version decision.

## Verification and reciprocal mapping

The acceptance surface is: clauseforge-api-schema, api/openapi.json, frontend/src/api/client.ts, API drift suite. The corresponding implementation and failure tests must cite ADR-004; if that path is removed, this decision is reopened rather than preserved as orphaned documentation.
