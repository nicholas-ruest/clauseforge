# ADR-010: Fail-closed upstream markers

**Status:** Accepted for ClauseForge 0.1  
**Decision date:** 2026-11-20

## Context

A successful process exit alone cannot prove that the intended upstream operation ran.

## Decision

Each adapter requires a capability-specific marker in stdout and returns a typed StageResult only after exit success and marker presence.

## Consequences

Misconfigured commands and help-only probes fail. Markers are supplementary to exact source verification and original logs, not standalone provenance.

## Verification and reciprocal mapping

The acceptance surface is: adapter failure tests and runtime wrappers. The corresponding implementation and failure tests must cite ADR-010; if that path is removed, this decision is reopened rather than preserved as orphaned documentation.
