# ADR-018: Cloud Run configuration only

**Status:** Accepted for ClauseForge 0.1  
**Decision date:** 2026-11-20

## Context

Deployment readiness is required while spending and production changes are not authorized.

## Decision

Check in a container contract, service YAML template and rollback instructions without invoking cloud deployment APIs.

## Consequences

Reviewers can reproduce a deployment plan. Image URI, project and authorized volume remain explicit reviewer inputs.

## Verification and reciprocal mapping

The acceptance surface is: deploy/cloud-run-service.yaml, deploy/ROLLBACK.md. The corresponding implementation and failure tests must cite ADR-018; if that path is removed, this decision is reopened rather than preserved as orphaned documentation.
