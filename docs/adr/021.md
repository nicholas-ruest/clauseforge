# ADR-021: API errors retain correlation

**Status:** Accepted for ClauseForge 0.1  
**Decision date:** 2026-11-20

## Context

Plain middleware strings are hard to join with domain failures and browser evidence.

## Decision

Domain errors serialize a typed ErrorResponse with correlation ID; outer authorization denials remain no-write and expose a stable textual reason plus response correlation header.

## Consequences

UI recovery can show useful detail without stack traces. Future middleware normalization will wrap all outer errors in the same JSON schema.

## Verification and reciprocal mapping

The acceptance surface is: ErrorResponse, service error mapper, middleware matrix. The corresponding implementation and failure tests must cite ADR-021; if that path is removed, this decision is reopened rather than preserved as orphaned documentation.
