# ADR-016: External exact-source evidence

**Status:** Accepted for ClauseForge 0.1  
**Decision date:** 2026-11-20

## Context

Evidence inside the checkout can be rewritten with the source it claims to prove.

## Decision

Collect suite logs and manifests outside the clean candidate, bind them to the committed SHA, and reject dirty or rebound sources.

## Consequences

Publication can verify immutable source/evidence correspondence. Local developers keep transient .evidence ignored.

## Verification and reciprocal mapping

The acceptance surface is: collect-product-evidence.sh, schema-v2 manifest, publication controller. The corresponding implementation and failure tests must cite ADR-016; if that path is removed, this decision is reopened rather than preserved as orphaned documentation.
