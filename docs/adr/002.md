# ADR-002: Policy before side effects

**Status:** Accepted for ClauseForge 0.1  
**Decision date:** 2026-11-20

## Context

A denied amendment review must prove zero calls to upstream systems and zero durable writes.

## Decision

Register authentication then authorization outside validation and domain execution. The role gate and blast-radius policy return before orchestration or adapter construction.

## Consequences

Denials are cheap and auditable. Middleware order is contract-tested; adding a new mutating route requires the same policy stack.

## Verification and reciprocal mapping

The acceptance surface is: service middleware, policy_denial_has_no_downstream_write test, denial-recovery browser journey. The corresponding implementation and failure tests must cite ADR-002; if that path is removed, this decision is reopened rather than preserved as orphaned documentation.
