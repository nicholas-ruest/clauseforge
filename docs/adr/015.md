# ADR-015: Immutable selection pins

**Status:** Accepted for ClauseForge 0.1  
**Decision date:** 2026-11-20

## Context

Default branches can move between research, probing, implementation and evidence collection.

## Decision

Every credited project uses a 40-character Git SHA, source URL and OSS license. Runtime wrappers compare checkout HEAD before calling the operation.

## Consequences

Upstream upgrades are explicit selection changes and require re-probing. Security patches are not silently inherited.

## Verification and reciprocal mapping

The acceptance surface is: selection-report.json, runtime verify function, integration matrix. The corresponding implementation and failure tests must cite ADR-015; if that path is removed, this decision is reopened rather than preserved as orphaned documentation.
