# ADR-011: No service-owned database

**Status:** Accepted for ClauseForge 0.1  
**Decision date:** 2026-11-20

## Context

A private database would violate the shared-storage boundary and complicate reset, audit and container portability.

## Decision

Use a configured evidence path and mount it as a shared volume. The service owns serialization rules, not a database server.

## Consequences

Local reset is deterministic and Cloud Run config can bind an authorized volume. Multi-region consistency is outside the prototype boundary.

## Verification and reciprocal mapping

The acceptance surface is: EvidenceStore, start/reset scripts, deployment config. The corresponding implementation and failure tests must cite ADR-011; if that path is removed, this decision is reopened rather than preserved as orphaned documentation.
