# ADR-013: Deterministic risk aggregation

**Status:** Accepted for ClauseForge 0.1  
**Decision date:** 2026-11-20

## Context

A risk score must be explainable across domain and upstream stages.

## Decision

Normalize every typed StageResult score into the closed interval and compute an arithmetic mean, retaining all stage names in evidence.

## Consequences

Simple aggregation supports ablation and audit. It is not claimed as a predictive probability; calibration changes require a new ADR and benchmark.

## Verification and reciprocal mapping

The acceptance surface is: clauseforge-orchestration, benchmark and ablation suites. The corresponding implementation and failure tests must cite ADR-013; if that path is removed, this decision is reopened rather than preserved as orphaned documentation.
