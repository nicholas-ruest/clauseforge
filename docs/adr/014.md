# ADR-014: Restart-safe browser evidence

**Status:** Accepted for ClauseForge 0.1  
**Decision date:** 2026-11-20

## Context

Page refresh alone is not durability proof if backend memory still holds the result.

## Decision

The evidence journey records a correlation ID, stops and restarts the Rust process, reloads the browser, and resolves the saved record from disk.

## Consequences

This makes process restart part of acceptance. Host loss requires the configured shared volume and is covered by deployment configuration, not local tests.

## Verification and reciprocal mapping

The acceptance surface is: browser-journeys.sh, durable retrieval test, external trace. The corresponding implementation and failure tests must cite ADR-014; if that path is removed, this decision is reopened rather than preserved as orphaned documentation.
