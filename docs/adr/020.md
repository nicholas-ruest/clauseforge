# ADR-020: Container network topology

**Status:** Accepted for ClauseForge 0.1  
**Decision date:** 2026-11-20

## Context

The host cannot provide /dev/net/tun to default slirp, and privileged containers are prohibited.

## Decision

Build a single unprivileged product image; smoke it with rootless Podman and host networking for localhost verification or network=none for binary-only checks.

## Consequences

The topology matches the authorized host boundary. No privileged flags or security-policy changes are needed.

## Verification and reciprocal mapping

The acceptance surface is: Containerfile, scripts/container-smoke.sh. The corresponding implementation and failure tests must cite ADR-020; if that path is removed, this decision is reopened rather than preserved as orphaned documentation.
