# Prototype acceptance map

## Primary outcome

The browser submits an authorized scenario. Correlation, authn, policy and deadline layers run; ten Rust domain stages and all eight pinned upstream operations return; audit reconstruction succeeds; the record is fsynced; the UI renders score, 18 stages, correlation and digest.

## Denial and recovery

The browser selects Observer. Authorization returns 403 before adapters or persistence. The test records audit length before and after and requires equality. Restoring the reviewer role reuses the authored input and completes the path.

## Durable retrieval

The browser opens Evidence and captures a correlation. The backend is terminated and started as a new process over the same evidence path. After refresh, the card with the same correlation and hash is rendered. Desktop and mobile screenshots plus Playwright traces are retained externally.
