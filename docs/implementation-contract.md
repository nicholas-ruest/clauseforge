# Implementation contract

The implementation is complete only when the React frontend, typed API, executable middleware, Rust composition root, 25 meaningful crates, seven selected upstream responsibilities, shared persistence and three browser journeys operate together. Each counted crate has a production caller plus behavior and failure tests. Each credited upstream has a pin, license, source URL, adapter call site and source-bound receipts.

The source commit must remain clean while external evidence is collected. The exact full-product wrapper, selection gate, backend gate, Rust-share verifier and publication controller are immutable. The collector executes rust, backend, frontend, API, middleware, integrations, benchmark, ablations, containers and browser suites. No skipped suite or handcrafted receipt is equivalent.

Publication is a later gated transition: only a complete local PASS and independent semantic review allow the controller to invoke `publish-via-pr.sh`. The publisher may target only `nicholas-ruest`, creates a review branch and non-draft PR, and never merges or deploys.
